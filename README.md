## 它能做什么

- 模拟电池、变流器（PCS）、变压器、断路器、并网点电表等设备行为  
- 通过 **Modbus TCP** 对外提供遥测与控制接口，EMS / 调试软件可按连真设备的方式接入  
- 提供 Web 主接线监视、电池堆簇查看、命令与自动化脚本等联调能力  

适用于：真机未到货、现场不能随意操作、需要反复验证同一工况、给客户或领导做演示。

> 本产品是**软件仿真**，不是硬件在环（HIL）实时孪生，聚焦策略验证与联调效率。
